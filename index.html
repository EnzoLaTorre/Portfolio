Sobre mí

Soy Enzo La Torre, desarrollador júnior con enfoque en el desarrollo de aplicaciones web. Me interesa construir soluciones funcionales y escalables, desde la interfaz de usuario hasta la lógica del servidor, y estoy comprometido con aprender y crecer constantemente.

Mi base está en el desarrollo front-end con HTML, CSS y JavaScript. Actualmente estoy profundizando en la programación orientada a objetos y fortaleciendo mis conocimientos de Git y GitHub para trabajar de forma profesional en equipo.

En el backend estoy aprendiendo Node.js y Express para crear APIs y entender la lógica del servidor. Al mismo tiempo estoy formándome en Vue, Vuetify y TypeScript para ampliar mis capacidades como desarrollador front-end.

Además, estoy adquiriendo conocimientos de Linux, metodología ágil e inglés para completar mi perfil. Busco mi primera oportunidad laboral para integrarme a un equipo, contribuir con entusiasmo y seguir evolucionando como profesional.

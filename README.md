Portafolio personal responsive con diseño oscuro moderno, animaciones y validación de formulario, construido solo con **HTML, CSS y JavaScript**.

A personal responsive portfolio with a modern dark design, animations, and form validation, built with **HTML, CSS and JavaScript** only.

## 🌐 Sitio en línea / Live site

👉 [https://enzolatorre.github.io](https://enzolatorre.github.io)

## 📑 Secciones del sitio / Site sections

- **Inicio / Home** — presentación y CTA.
- **Sobre mí / About me** — perfil y formación.
- **Tecnologías / Technologies** — stack y habilidades.
- **Proyectos / Projects** — tarjetas generadas desde `data/projects.js`.
- **Contacto / Contact** — formulario con validación.

---

## ✨ Características principales / Key features

- 📱 **Responsive** — escritorio, tablet y celular / desktop, tablet and mobile.
- 🌙 **Tema oscuro moderno** con acentos neon / modern dark theme with neon accents.
- 🎨 **Tipografías** Inter, JetBrains Mono y Space Grotesk (Google Fonts).
- ✨ **Animaciones y microinteracciones** (scroll reveal, hover effects).
- 🗂️ **Generación dinámica de proyectos** desde `data/projects.js` / dynamic project cards.
- 📝 **Validación de formulario de contacto** en el cliente / client-side contact form validation.
- ♿ **Accesibilidad** — `aria-label`, focus visible, HTML semántico / accessibility.
- ⚡ **Sin frameworks ni dependencias** / no frameworks or dependencies.

---

## 🛠️ Stack tecnológico / Tech stack

- **HTML5** — Estructura semántica.
- **CSS3** — Variables CSS, animaciones y diseño responsive.
- **JavaScript (ES6+)** — Interactividad y generación dinámica de contenido.

> Sin dependencias externas (solo Google Fonts) / No external dependencies (only Google Fonts).

---

## 📁 Estructura del proyecto / Project structure

```
enzolatorre.github.io/
├── index.html      # Estructura del sitio / site structure
├── style.css       # Estilos, tema oscuro, animaciones, responsive
├── script.js       # Interactividad y renderizado de proyectos
├── README.md       # Documentación del proyecto / project docs
└── data/           # Datos del portafolio / portfolio data
    └── projects.js # Proyectos renderizados en la grilla / projects data
```

> 📌 **Proyectos:** para agregar uno, edita `data/projects.js` — no hace falta tocar el resto.
> **Projects:** to add one, edit `data/projects.js` — no need to touch anything else.

---

## 🚀 Cómo ejecutar / How to run

1. Clona o descarga el repositorio / Clone or download the repo.
2. Abre `index.html` en tu navegador / Open `index.html` in your browser.

No requiere instalación ni backend / No installation or backend required.
